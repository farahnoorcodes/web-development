CSS Selector

Element selector:

In CSS, an element selector targets HTML tags directly by their tag name — no dot, no hash, just the tag name itself.

basic syntax:

tagname {
        property: value;
    }
hey! i'm div .
hey! i'm second div.

This means: every tag on the page gets same color text at same background, same decoration and same size, etc — you're not targeting one specific paragraph, you're targeting the whole element type.

Class selector

A class selector targets any HTML element that has a matching class attribute — you can reuse the same class on as many elements as you want, which is the main thing that sets it apart from an ID selector (which must be unique).

Basic syntax:

.className {
        property: value;
    }

Note the . (dot) before the class name — that's what tells CSS "this is a class selector."

A few things worth knowing:
One element can have multiple classes, separated by spaces:

.decore{text-decoration-line: underline;}

Both rules apply to that one <p>.
Combine a class with an element selector to be more specific — this only targets

tags with the highlight class, not other elements that might also use it:

Example:

paragraph with class red.

CSS for this line specifically:

p.red { color: red; }

Naming convention: use lowercase, hyphen-separated names for multi-word classes (btn-primary, not btnPrimary or BtnPrimary) — this is the common CSS convention, similar to how you'd use camelCase in Java variable names.

id selector:

An ID selector targets the one element with a matching id attribute. Unlike a class, an ID should only be used once per page — it's meant to identify a single, unique element.

Basic syntax:

#idName {
    property: value;
}

Note the # (hash) before the name — that's what marks it as an ID selector, versus . for a class.

Child selector:

A child selector (>) targets only the direct children of an element — one level down, not deeper.

Basic syntax:

parent > child {
    property: value;
}
example:

Direct child — gets styled

Grandchild — does NOT get styled

For the paragraph to get styled, we write the CSS code like:

.container > p {
    color: red;
}

descendant selector

A descendant selector targets an element that appears anywhere inside another element — no matter how many levels deep it's nested.

Written as two (or more) selectors separated by a space — that space is what makes it a descendant selector.

Direct child — styled

Grandchild — also styled

Great-grandchild — still styled

CSS for this code:

.desc p {
    color: blue;
}
