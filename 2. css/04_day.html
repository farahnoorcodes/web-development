Text Decortion

1. text decoration - line:

overline: you can over line an element or tag on web page.

underline: you can also do the same with under line.

none: if don;t want any line.

line-through: if you want line over thr text.

you can apply many decorations on the line

2. Text decoration - color:

Sets the color of the decoration line, independent of the text color.
Example idea: red underline under black text — the line color doesn't have to match the text color.

text with different underline color

3. Text Decoration - style:

solid: straight line with no break

Dotted: dotted line instead of straight line.

double: double line instead of a single line

wavy: wavy line instead of a straight line

dashed: dash line will produce instead of simple dotted line

4. Text Decoration - thickness:

you can adjust the thickness of the text decoration as you want.

thickness is adjust using em

thickness using auto keyword

thickness using from-font keyword

5. Text Underline - offset:

Adjusts the distance between the underline and the text itself. Only affects underline, not other lines. Useful for improving readability when text is close to its underline.

6. shorthand syntax:

All the above can be combined into one shorthand property:
text-decoration: [line] [color] [style] [thickness];
Order doesn't strictly matter, but this is the conventional order. You don't need to specify all of them — omitted parts use their defaults.
